# 路线图：先把练习闭环做实，再扩展平台

> 2026-11-17 修订。基线 `7b9f12e` / package v1.6.4；本轮目标 v1.7.0，目标不等于已发布。规划按验收推进，不给未经验证的日期、用户规模或效果承诺。

**先讲一段，再看一处；先有证据，再谈平台。** OpenPodium · 开讲从体态镜更名，面向个人试讲与表达练习。主力站为 [openpodium.chensibo.cn](https://openpodium.chensibo.cn/)，Pages 仅兼容入口，不是第二个主站，也不与独立产品 kaijiang.chensibo.cn 混同。

## 1. 当前实现与边界

| 能力 | 当前状态 |
|---|---|
| 浏览器视觉、短练习与课堂、回放、本机历史与导出 | 已有实现；不等于本轮已完成真人、长时和实体手机验证。录像默认不保存，无云同步。 |
| 本机中文听写 | 已接入 sherpa-onnx WASM + Paraformer int8，约 90 MiB；默认不自动下载，旧显式开启设置保留。缓存齐全时可本机识别。 |
| 浏览器听写 | 已接入 Web Speech，可能传音到厂商，国内可用性受网络限制。没有转写不等于口头禅为零。 |
| 轻量 Three 演示 | 仅 demo 与演示回放懒加载；动画 rig 投影、骨架、字幕与结果是预设，不是真人检测或 ASR。真实练习零 Three；可降为 2D。 |
| 模拟课堂／路演 | 本机规则与 2D 插画文字，不是联网智能体或真人反馈。 |
| 视频导入 | 仅视觉，不转写、不统计口头禅、不入历史。 |
| Core 与场景解释分离 | 部分实现；中立观测是原则，完整解耦、稳定扩展协议还未完成。 |
| 服务器 ASR | provider 正在实施，公网可达和上线未确认，按**未上线**管理。模型资源托管不是服务端推理。 |
| 账号、安全收费、业务／团队后台、插件 SDK／市场 | 未上线／未交付。trial/pro 是前端开关，不是安全授权；体验上传端点当前为空。 |
| 桌面／移动发行、小程序 | Tauri / Capacitor 有脚手架，不等于签名安装包或商店发行；小程序未交付。 |

视觉首次需要模型与 WASM 下载，不承诺默认全离线。细节见 [ASR](ASR.md)、[隐私](PRIVACY.md)、[功能说明](../README.md)。保留 `titaojing-*` 等旧技术 ID、存储键和兼容路径，避免直接更名破坏历史。

## 2. P0：v1.7.0 本轮目标与发布门槛

下面是本轮工作方向，不是已完成清单；完成项必须以实际改动和检查为证。

1. **事实一致**：更新过期的全去 3D、自动下载、占位和默认全离线措辞；区分当前、历史、在做与规划。
2. **来源与缺失**：真实摄像头、导入、预设 demo 在界面／回放／打印中不混淆；无语音时明确缺失，不伪造零次数或转写。
3. **报告证据**：先交代时刻、来源、观测，再给场景解释与下一步；不把面向镜头推成真实眼神交流，不把规则评价当教学质量认证。
4. **最小真实闭环**：取得参与者许可后，完成准备→练习→结束→回看具体时刻→本人选一处复练。没有真实样本前只展示明确标注的预设交互。
5. **发布契约**：修齐 tag 触发与 Release job；Pages、制品入库与主站手动切换分别记录，不以 CI 绿灯代替上线验收。
6. **服务器 provider**：代码实现、服务启动、公网接通、隐私与失败降级分别验收；没有发布负责人上线确认前文档仍标未上线。

## 3. P1：真实验证、架构与界面

- 真机矩阵：Windows / macOS 笔记本优先，实体 iPhone / 安卓单列；拒权、断网、模型缺失、后台切换、长时练习、保存失败和结束收尾均要记录。桌面手机视口不叫实体手机测试。
- 效果小样本：有授权与人工标注后测视觉事件误差、中文 CER、语气词漏报／误报、时间戳偏差；不从 CI 或合成训练推导准确率和改善效果。
- 逐步分离 Core 与 Scenario：先固定来源、覆盖率、可用性、时间戳和规则版本契约，再迁移解释逻辑；保持旧历史可读，不直接大拆或宣称已有 SDK。
- 界面方向待确认：现有纸墨风格做减法与“暖白练习室／松绿”都是候选，不将未经批准的皮肤写成定稿。
- 上传／研究功能若启用，先明确接收方、用途、授权、保留与删除，不将本机 opt-in 队列当已开通后台。

## 4. P2：可选服务与多端，不先画交付饼

### 可选服务器录后转写

先从许可清楚的公开音频与单作业基准开始，固定引擎、模型、线程数和设备条件；测 RTF、冷启动、内存、队列等待、失败率与递增负载，再决定可承载范围。没有证据不写 GPU 能力、不承诺并发人数。实时 ASR 另开范围。

上传必须主动同意，明确音频接收方、加密传输、鉴权／限额、取消重试、保留期限和删除方式；拒绝上传仍可做本地视觉或自选本机听写。公网、成本和数据责任未确认前，不宣传“免下载服务器识别已可用”。

### 一套网页核心，多端外壳

| 平台 | 方案／验收前提 |
|---|---|
| 网页 / PWA | 当前主力；HTTPS、权限、Service Worker 与资源缓存需实测。“添加到主屏幕”不保证首次离线或各浏览器相同体验。 |
| Windows / macOS | Tauri 骨架在 [`apps/desktop/`](../apps/desktop/)；需验证系统 WebView 的镜头、音频、缓存、下载、本机听写，以及签名／公证和安装更新。不能依赖 Web Speech 普遍可用。 |
| 安卓 / iOS | Capacitor 骨架在 [`apps/mobile/`](../apps/mobile/)；需独立验证权限、WebView／原生语音、后台行为、签名及商店要求。尚无本轮可分发包证据。 |
| 微信小程序 | DOM、MediaPipe 与资源限制使其不能直接复用网页；web-view 权限、业务域名和原生重写都待调研，不承诺能试讲。 |

早期方案中的固定资源大小、签名价格和商店政策不是当前报价或合规结论，实施前按实际制品与官方要求复核。

### 团队与商业方向

代码以 Apache-2.0 开源；机构部署、班级／课程管理、教师端报告、组织权限和培训服务只是需求假设。先验证真实协作需求、数据归属、越权防护、退出删除与运维责任，再设计服务，不把前端激活码当收费安全，也不声称已有客户、收入或学校认证。

插件 SDK／市场必须等核心契约稳定、真实第三方需求与兼容安全模型具备后再评估。研究数据集、论文和校方合作需要真实许可与证据，不预设人数或成果。

## 5. 版本、CI 与上线不是同一件事

采用语义化版本 `主.次.修订`。发布前由负责版本的会话同步 package、变更记录与实际交付范围；文档目标版本不能替代源码版本。构建号为 `版本-内容哈希`，**哈希后缀不是 Git SHA**，追溯时另记提交号。

| 事件 | 实际结果 | 不代表什么 |
|---|---|---|
| PR、main push、手动 CI | 文档、测试、构建、冒烟与合成训练检查 | 不代表真人效果、主站部署或服务器 ASR 可用 |
| 推送 `v*` tag | 同一 CI 先测试，再校验 tag 与 package 版本一致，构建 zip 并上传 GitHub Release；含 `-` 的 tag 标为预发布 | 不切换主站；Release zip 是测试分发包，不是直接上传主站的根目录 |
| main push / 手动 Pages | 独立 Pages 工作流发布兼容入口 | 不等于主站更新，也不代替 CI 验收 |
| 手动主站发布 | 白名单 `dist/`、清单与哈希验证后，保留 previous，原子切 current | 仍需公网资源、交互与缓存验收 |

当前没有已开通的 beta 独立站承诺；预发布 tag 不会自动创建体验站。主力站发布与回滚见 [部署指南](DEPLOY.md)。
