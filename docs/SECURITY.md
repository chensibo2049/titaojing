# 安全说明

## 报告漏洞

如果发现可以把别人的摄像头、麦克风、本机历史或体验计划队列取走，或可以在未同意时把数据发到外部，请不要公开 Issue。请发邮件给项目维护者，或通过仓库的私密通报渠道（GitHub Security Advisory / CNB 对等功能）告知。我们会在确认后尽快修复，并在 CHANGELOG 里说明（不暴露利用细节）。

请不要在报告里附上真实试讲录像或可识别的人脸截图。

## 本项目需要知道的边界

- 体态镜是静态网页，没有自己的用户服务器。`config.js` 里的试用版开关、测试激活码、体验计划上传地址都不是安全机制：能改文件的人就能改它们。正式授权需要另外部署后端，并替换 `src/license.js`。
- 浏览器听写会把声音送到厂商服务，这不是漏洞，但必须在界面上写明。
- 体验计划的发送函数在每次调用时都会再次检查同意状态和端点；端点为空或未同意时不会发起网络请求。若你自行填写了端点，请使用 https，并只接收本文档和 `PRIVACY.md` 中列出的字段。
- 依赖（MediaPipe、esbuild 等）用锁文件固定版本；模型与 WASM 用 sha256 校验（`assets/mediapipe/manifest.json`）。
