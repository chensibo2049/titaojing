# 转写与口头禅：当前能力、数据去向与历史

> 2026-11-17 修订；基线为 `7b9f12e` / v1.6.4，本轮目标 v1.7.0，不代表已发布。本文按源码说明实现范围；历史实测单列，不作为本轮新测试。

听写是可选项。没有转写时仍可做视觉练习，但不能把“未识别”解释成“没有口头禅”。口头禅统计受 ASR 漏字、改写和词表影响，不是精确计数。

## 1. 三种路径，分清下载与推理

| 路径 | 识别在哪里 | 下载与网络 | 状态和隐私 |
|---|---|---|---|
| 本机中文听写 | 用户浏览器 Worker；sherpa-onnx WASM + Paraformer int8 | 首次引擎与模型约 90 MiB，缓存后复用 | **已接入，不是占位**；识别时不上传声音。资源齐全、浏览器兼容时可离线运行。 |
| 浏览器听写 Web Speech | 由浏览器／系统厂商决定 | 不用下载本项目中文权重包，通常依赖网络和厂商服务 | 已接入；可能向厂商传输声音，不能承诺完全离线，在中国大陆可能连不上。 |
| 自建服务器 ASR | 需要独立服务器推理和上传链路 | 用户不用下载识别权重，但要上传音频 | provider 正在实施，公网接通与上线未确认，当前标为**未上线**；不保证可用、并发或成本。 |

`config.js` 的 `asrModelBase` 仅改变模型文件下载来源；**资源托管 ≠ 服务器推理**。给模型换下载 URL 不会得到服务器转写。

### 默认行为

- 新用户的 `asrAutoDownload` 默认 **false**；在设置里主动下载，或自行开启自动下载。旧设置中显式开启的值仍保留。
- “自动”模式在本机模型和引擎就绪时优先本机，否则尝试浏览器听写；浏览器网络失败且本机已就绪时可切本机。
- “仅本机听写”未就绪时会提示缺模型，不偷偷转在线；本次语音统计缺失，视觉分析仍可继续。
- 默认不自动下载不等于永远不联网：页面、视觉资源、听写引擎与主动选择的模型下载均可能产生资源请求。

对应实现：`src/settings.js`、`src/asr-ui.js`、`src/asr.js`、`src/asr-sherpa.js`。demo 字幕是预设，不经过这些 ASR 链路，不是识别效果证据。

## 2. 本机听写组成与下载

以 [`assets/asr/manifest.json`](../assets/asr/manifest.json) 的文件大小、来源、许可与 sha256 为准，下面是量级，不混用 MB 与 MiB 精确值。

| 部分 | 实现 | 大小量级／许可 |
|---|---|---|
| 引擎 | sherpa-onnx WebAssembly，含 onnxruntime；JS、WASM 随静态站发布 | WASM 11,722,172 字节，另有 JS；Apache-2.0，onnxruntime 为 MIT |
| 切句 | Silero VAD | 约 0.6 MiB，MIT |
| 中文模型 | `sherpa-onnx-paraformer-zh-small-2024-03-09`，Paraformer int8；FunASR 训练、k2-fsa 导出 | 权重 81,828,675 字节，tokens 75,352 字节；模型卡标注 Apache-2.0，保留来源并在再分发前复核许可 |

引擎、VAD、权重与 tokens 合计约 **90 MiB**。不是自研基础模型；中文权重按需下载，不随普通网站制品分发。

### 下载来源与缓存

按清单顺序尝试：部署方 `asrModelBase`（若配置）→ ModelScope（modelscope.cn）→ hf-mirror.com → Hugging Face。跨域、重定向、Range 与镜像可达性取决于实际网络，本轮未重测国内速度或可达性。

下载实现 `src/asr-model.js` 支持 4 MiB 分段、最多 5 路并行、断点续传、sha256 校验；不支持 Range 时退回单路。分段暂存 IndexedDB，校验通过后写入 Cache Storage，并尝试请求持久存储。

旧存储技术 ID 保留：模型缓存 `titaojing-asr-model-<模型名>`，引擎缓存 `titaojing-asr-engine-*`。更名不直接重命名这些键。设置中可删除模型，但不把它说成一键清除所有引擎缓存和残余分段；浏览器清站点数据可清除该域的本机记录与缓存，也会丢失历史。浏览器回收缓存、隐私模式、换域名或设备后可能需要重下，不承诺“一次下载永久可用”。

资源服务器仍可记录 IP、请求时间等访问日志；下载模型不上传练习音频。详见 [隐私说明](PRIVACY.md)。

## 3. 运行方式与限制

- `src/asr-sherpa.js` 启动 `assets/asr/engine/asr-worker.js`；Worker 从缓存读模型，避免在页面主线程执行识别。
- 克隆摄像头流的音轨，经 AudioWorklet 转为 16 kHz 单声道，旧浏览器退回 ScriptProcessor。
- VAD 在停顿约 0.35 秒后切句，单句最长 12 秒；文字通过 `onTranscript` / `onFiller` 进入报告。时间戳是切句与排队延迟修正后的估计，不是精确逐字对齐。
- 站位页可在资源已就绪时预热；结束时最多等约 2.5 秒收尾。是否在具体设备无丢句仍需验证。
- “试一下听写”在模型就绪且未选仅浏览器时测试本机路径；调试可用 `?debug=1`，日志中的转写可能敏感。

本机听写只识别普通话；“识别语言”设置只影响浏览器听写。结果通常整句出现，不是逐字流式。轻声、短促或粘连的“嗯／啊”会漏识别，气声也可能误识别，不能把统计当真实总数。

需要支持 WebAssembly、Worker 与音频管线的浏览器，以及 HTTPS 或 localhost。旧电脑可能有 CPU 压力，移动浏览器／WebView 需单独验证。**本地视频导入当前只分析视觉，不分析音轨、不转写、不统计口头禅、不写历史**，不能当录后服务器转写入口。

## 4. 历史记录（不代表本轮复测）

### v1.1.0 占位阶段

当时已经收集浏览器完整转写、标出词表命中和提示网络失败；本机模块仍为明确不可用的占位。该描述仅适用于 v1.1.0，不适用于当前已接入的 sherpa 路径。

### v1.2.0 接入本机识别；2026-11-14 测试记录

旧记录使用 `node scripts/asr-real.mjs`、无头 Chrome 与 `--use-file-for-fake-audio-capture`，把 WAV 送入麦克风链路，并非实体麦克风现场测试：

- 输入为 k2-fsa 公开真人普通话 `test_wavs/0.wav`（约 5.6 秒）。当时 ModelScope 下载与校验约 24 秒，引擎载入约 1.4–1.9 秒；转写包含“对我做了介绍啊那么我想说的是呢大家如果对我的研究感兴趣呢”。
- 20 秒循环输入的回放出现逐句转写，并统计到“啊”。
- 合成语音勾股定理样本识别出“嗯”，但一次漏掉句首“啊”；离线对照中 Paraformer 保留“嗯／啊”优于当时选用的 Zipformer CTC 小模型，因此选 Paraformer。

这些只是固定小样本的历史结果，不代表准确率、真实课堂或所有设备表现。本轮未运行重型测试、未下载模型。手动测试工作流为 `.github/workflows/asr-real.yml`，不在每次普通 CI 中执行；工作流旧名称中的“真机”不能当实体设备证据。

### v1.3.0 自动下载阶段（旧默认，现已变更）

该阶段曾进入页面即后台下载，支持设置关闭、省流量门控、进度、续传和可用时的 Background Fetch。当前新用户默认已改为不自动下载，不应照旧说明使用。

同阶段旧测试记录：测试机到 ModelScope 的 Range 返回 206，CORS 为 `*`；约 78 MiB 权重单路约 30.3 MB/s、五路约 19.4 MB/s，校验通过。hf-mirror 在当时海外测试机跳转至 Hugging Face，重定向缺 CORS；国内行为未实测。这些是旧环境结果，不是当前带宽承诺。

### 早期候选与未实现项

早期比较过 SenseVoice、Zipformer、关键词检测 KWS、FunASR 服务器方案、Whisper；它们是选型记录，不是已交付的多引擎能力。尤其“下一步换成本机识别”和“发现模型也不会真正识别”已被 v1.2.0 后实现替代。

## 5. 下一步验收

1. 获授权的真实短练习与长录音：分别测 CER、语气词召回／误报、时间偏差和长时稳定性；真人与合成音频分开记录。
2. 验证国内下载、断网、缓存被回收、拒绝权限、旧设备和结束收尾；缺失时不生成伪转写或零次数表扬。
3. 服务器 provider 只有在部署、公网链路与上传同意／限额／保留删除机制均获确认后，才改为上线；未压测前不承诺 CPU/GPU、并发、延迟或成本。
4. 桌面／移动外壳的权限、缓存与音频链路独立验收，不由网页版已接入推导安装包已可用。
