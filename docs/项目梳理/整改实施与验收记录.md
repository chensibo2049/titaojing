## 已实施

| 领域 | 实施内容 |
|---|---|
| 产品与视觉 | 暖白松绿 tokens；静态首页与明确准备入口；介绍页与应用一致；演示标明预设，不冒充真实识别 |
| 观测与解释 | `observations.js` 中立版本化观测；`scenario-practice.js` 版本化练习建议；报告显示来源、规则版本和证据跳转 |
| 缺失与兼容 | 无视觉/无听写保留“未统计”；导入仅分析画面；旧历史 ID、标记、点评保留，不自动清理 |
| 会话安全 | 异步启动 identity+generation 门禁；收尾捕获会话/录像/选项；旧回调不污染新会话；保存不覆盖当前页面路由；保存中不刷新升级 |
| 听写收尾 | Web Speech 等待 end 或明确失败；Sherpa flush 超时拒绝；保留截止前末句，关闭迟到结果 |
| 隐私 | 服务器录后上传要求本次明确同意、访问码、健康探测、音频限制；pagehide/hashchange 清除私密输入并取消任务；不把请求 DELETE 称作已核验删除 |
| 发布 | 制品含 sourceCommit/sourceDirty 与逐文件 SHA256；严格发布拒绝脏树/不匹配源码/额外文件/符号链接；复用静态 release/current/previous 原子切换，不改 nginx |
