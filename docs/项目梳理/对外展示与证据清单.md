## 2. 可直接使用的诚实简短介绍

### 一句话

**OpenPodium · 开讲，是一面给试讲与表达练习用的镜子：讲一段，回看一个具体时刻，找到下一次能改的一处。**

### 约半分钟

开讲从体态镜更名而来，帮助练习者留下动作、面向估计与语言线索，再回到具体时刻自查。当前以浏览器本机视觉分析、回放和本机记录为主，听写可选浏览器服务或下载模型后的本机识别。预设演示只说明交互，不代表真人识别效果。它不是考试评分系统，也不把缺失数据当作零分；团队后台和服务器转写仍在规划评估中。

### 技术补充（按需）

视觉使用 MediaPipe，本机中文听写使用 sherpa-onnx WASM 与 Paraformer int8；不是自研基础模型。用户下载听写包是为了在本机识别，服务器托管模型文件不等于服务器进行 ASR 推理。浏览器在线听写可能把声音送到浏览器厂商，应按选择说明隐私。

## 3. 一次真实案例的展示脚本（空白模板，不生成数据）

目标不是表演“识别得很神”，而是让观众看到一位练习者如何找到可复练的一处。

1. **展示前许可**：成年参与者明确同意录制、展示范围、保存期限和撤回方式；不含未授权学生／同伴。公开场合优先使用已审查片段；不现场上传到第三方识别服务。若无许可，就只展示预设交互，标题明确“预设样本”。
2. **来源与版本卡**：填写实际日期、设备／浏览器、生产构建号、输入为“实时真人”、是否保存录像、听写模式；展示时不公开姓名或设备私人信息。
3. **讲两分钟**：由本人选真实题目；自然练习，不刻意预演命中规则。现场失败就说明失败原因，不用 demo 偷换结果。
4. **回看一个时刻**：从真实报告选择实际存在的时间戳，播放前后语境；若需要画面回看，事先取得本机保存录像同意。对照原画面／原音说明“观察到了什么”“算法估计了什么”“无法判断什么”。
5. **让本人决定一处改动**：记录本人原话，如“下次我想改的是：____”；不替本人填写成功感言，不凭算法替老师评成绩。
6. **同题短复练（可选）**：尽量同设备同距离；只展示实际差异，不把一次差异推成因果效果。没变好也如实记录。
7. **收尾**：展示本机记录与删除入口；按同意范围处理导出物。记录卡保存真实证据引用和缺失项，不能为凑完整填造数据。

### 采证卡必填项（目前均待采）

| 类别 | 要保存的内容 |
|---|---|
| 来源 | 同意记录引用、脱敏案例 ID、设备与浏览器、版本、输入与听写模式 |
| 完整链路 | 开始／结束、实际时长、回放来源、录像是否可用、真实转写是否存在 |
| 可核验时刻 | 时间戳、对应原始依据、观测、解释、缺失、人工复核意见 |
| 用户价值 | 本人能否找到该时刻、本人选择的一处改动、复练原话与是否愿再用 |
| 留存与删除 | 授权范围、保留期限、存放责任人、导出副本与删除记录 |

## 5. 四条就绪门槛

1. **真实**：输入与来源标签不混淆；真人、导入、预设分开；结果有原始依据。
2. **完整**：展示从进入到回看再到下一步行动，不只展示一个漂亮屏幕；失败／缺失也能完成交代。
3. **可核验**：版本、设备、模式、时间戳、授权与证据链可复查；内部材料与外部稿分别审查。
4. **用户价值**：练习者自己找到一个具体时刻、选出一个可复练动作；不是仅开发者声称“功能很多”。

四项均通过后才将对应案例用于效果展示；此前可诚实展示产品方向和预设交互。任务责任见[执行清单](执行优先级与验收清单.md)。
