## 一页结论（当前最佳版）

- **唯一定位**：OpenPodium · 开讲，从体态镜更名，是帮助试讲与表达者回看自己表现的练习工具；不是另一个独立产品 kaijiang.chensibo.cn。
- **价值主线建议**：讲两分钟 → 回看一个具体时刻 → 找到下一次改的一处。中立观测属于 Core，解释和评价由场景模块提供，是目标架构，不应假称已经完全解耦。
- **产品事实**：当前仓库是浏览器静态应用；有视觉观测、练习、回放、报告、本机记录与可选听写实现。没有已实现的业务后台、服务器 ASR 推理、插件 SDK/市场或团队管理后台。
- **真实与 demo 分开**：demo 用于解释交互与场景，不是识别准确率或真实用户效果证据。3D 的历史变动必须按版本解释，不能再用“全部永久去掉”概括现状。
- **版本矛盾已定位，未强行同步工作区**：本地 HEAD=`a3121f8`、package=`1.6.3`、dist=`1.6.3-8797b171`；独立查询远端 main=`7b9f12e`（PR10），公网 version=`1.6.4-1a636413`（HTTP 200）。生产报告在提交与版本元数据层面得到印证；这是本地分支／制品与生产不同步，不能把本地状态当生产状态，也不能由 version 推断全部资源／真实效果已通过。
- **模型事实**：浏览器 Web Speech 与 sherpa-onnx WASM 本机中文 Paraformer int8 是两条路径。下载模型是让用户设备执行推理；服务器托管下载资源不等于服务器执行推理。默认自动下载行为以源码为准，旧 ASR 文档存在相反陈述。
- **体验方向尚未批准**：暖白练习室、暖白与松绿、工具型界面仅为建议，不是已批准皮肤。先理顺闭环与报告证据，再讨论视觉落地。
- **对外门槛**：真实、完整、可核验、用户价值。CI 只能证明指定自动化检查通过，不能证明真实使用效果。
