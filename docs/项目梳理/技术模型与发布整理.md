## 2. 有没有后台：有静态托管，没有业务后台

证据：`docs/SECURITY.md:11-14` 声明静态网页；`config.js:38-57` 的授权、体验上传、镜像、账号端点均为空；`src/experience.js:117-125` 在无同意或无端点时拒绝发送。本轮公网定向读取 config.js 的这些非敏感字段也为空。

| 看起来像后台的东西 | 实际是什么 |
|---|---|
| 网站服务器、nginx、release | 静态文件分发与版本切换，不是业务应用服务器 |
| 本机档案／历史 | IndexedDB，不是账号数据库或团队后台 |
| 激活／trial/pro | 前端功能开关，`config.js:4-7,12-30`；试用本机历史上限 5，不是安全收费授权 |
| 注册／登录入口 | 服务地址未开通，不等于已有认证、权限和跨设备同步 |
| 体验队列 | 本机可选队列与发送函数，不等于已部署接收系统 |

**最小后台需求（规划，非上线）**：若仅解决下载负担，先做可选录后 ASR 作业，不必同时建团队系统；包含显式上传同意、身份／匿名作业凭证、限额与队列、状态与失败重试、结果时间戳、加密传输、访问控制、保留时限／删除、日志去敏、监控与滥用防护。团队版另需组织／成员／角色／报告授权、审计、导出与退出删除，不以“加个登录”代替。

## 3. ASR 模式矩阵与为什么要下载

| 模式 | 识别在哪里 | 用户下载／网络 | 当前状态 | 隐私与失败 |
|---|---|---|---|---|
| Web Speech 浏览器听写 | 浏览器／系统厂商路径，常用在线服务 | 不需本项目中文权重包；依赖浏览器支持与网络 | 已有 `src/asr.js:38-90`、`src/speech.js` | Chrome/Edge 可能传音到厂商；不经过本项目服务器，不能说完全离线 |
| sherpa-onnx WASM + Paraformer int8 | 用户浏览器 Worker，本机 CPU | 首次约 90 MB 级（产品常用约数），缓存后复用；需兼容 WASM/Worker | 已接入，不是占位（`src/asr-sherpa.js:175`） | 本机识别不上传音频；可能丢语气词、旧设备慢、缓存可能被回收 |
| 自建服务器托管模型文件 | 仍由用户浏览器识别 | 仍要下载；仅资源来源变更 | `config.js:51-54`、`src/asr-model.js:110-114` 支持镜像，当前为空 | 是资源分发，不是服务器转写；镜像仍有访问日志 |
| 自建服务器录后转写 | 服务端 CPU／未来经验证的 GPU | 用户不用下载识别权重，需上传音频 | **未实现，推荐候选** | 显式同意、队列、保留与删除机制先行；有带宽／算力／运维成本 |
| 服务器实时 ASR | 服务端持续接流 | 连续上传、稳定连接 | 未实现；不列近期默认承诺 | 更复杂的延迟、并发、断线与隐私问题 |
| 可选离线包 | 用户本机 | 先主动下载、校验、缓存 | 浏览器本机路径已有；独立原生包分发仍需验收 | “离线”是资源缓存就绪后的条件，不是首次访问零联网 |

下载是把推理所需的引擎和权重放到用户设备，换取数据留在本机与后续离线；把模型文件搬到自建站点不会让服务器开始识别。若不想让用户下载，必须新建服务端推理与上传链路，不是改一个 URL 就完成。

### 模型、体积与默认行为

- 清单 `assets/asr/manifest.json:35-65`：`sherpa-onnx-paraformer-zh-small-2024-03-09`，Paraformer 中文 int8；权重 81,828,675 字节，tokens 75,352 字节。引擎 wasm 11,722,172 字节，另有 JS/VAD（`:7-31`）。合计约 90 MiB 量级；旧文档 MB/MiB 混用，不应把约数当精确制品大小。
- 来源：FunASR 训练、k2-fsa 导出；清单记录许可和 sha256。再分发应保留来源并复核许可，不称自研模型。
- **新用户默认不自动下载**：`src/settings.js:21-22,54-55`；旧设置中显式 true 会保留。`src/asr-ui.js:59` 禁止默认自动下载。旧 `docs/ASR.md:5-7` 的自动下载说明已过期，`:90` “尚未真正识别”也已过期。
- 仅本机模式没缓存时不偷偷转在线：`src/asr.js:47-55` 返回不支持并解释缺失；auto 模式优先本机、可用时处理浏览器网络失败切换（`:79-85`）。
- 下载支持镜像、Range 分段／续传、sha256 校验、Cache Storage 与分段 IndexedDB（`src/asr-model.js:6-11,63-85,110-114,194-218`）。镜像可达性与国内各网络速度本轮未测。

## 4. 模型与用户数据生命周期

| 对象 | 获取／产生 | 保存／用途 | 删除／风险 |
|---|---|---|---|
| 视觉模型与 WASM | 首次需要时从站点加载 | 浏览器资源缓存、本机推理 | SW／缓存更新、首次带宽与设备性能需验证；不是零下载 |
| 听写模型 | 用户主动下载或曾主动开启自动下载 | 分段缓存 → 校验 → 模型 Cache Storage → Worker 读取 | 设置删除模型（`src/asr-model.js:81-85`）；引擎缓存、残余分段是否同步清理待验证，不能保证一次删除清空所有相关数据 |
| 实时流／可选录像 | 用户授权摄像头麦克风；MediaRecorder（`src/main.js:880-891`） | 默认录像不入历史；勾选后 IndexedDB | 单次／只删录像／全清（`src/store.js:73-91`）；不做云备份承诺 |
| 关键点、事件、转写、题干 | 实时分析 | 本机会话与历史；本机报告 | 按记录删除；用户导出的文件须自行保管，浏览器删除不会撤回已导出副本 |
| 导入视频 | 用户选本地文件 | 当前内存／对象 URL、只视觉回放 | 不进历史；本轮未验证释放／异常退出所有路径 |
| 体验队列 | 默认关闭，主动 opt-in 后 | 可包含转写、统计、摘要、最多三图（`docs/PRIVACY.md:23-38`） | 当前端点为空不发送；启用前必须重新明确用途与期限，不能对外写永远无上传能力 |
| 调试轨迹／反馈 | 用户主动导出 | 本机文件，不默认自动上报 | 关键点和文本仍可能敏感；真人研究必须另行知情同意，不把“不含视频”当匿名 |

对外隐私话术必须逐模式说明，不写“所有情况下音视频绝不离开设备”。隐私说明中的旧品牌与自动模式细节需后续统一。本轮不上传真人素材，不启用体验队列。

## 5. 服务端 ASR 验证方案（待办，不执行）

用户提供的上次机器核查：20 物理核／40 线程 E5-2640 v4、约 31 GiB 内存；**本轮未复核，没有推理 GPU 证据，没有 ASR 压测**。核心数量不能推导并发人数。

1. Researcher 与 Operator 先只读确认可用资源、已有服务负载、资源预算；Developer 固定候选引擎／模型／线程数及许可。先 CPU 单作业录后转写，不假设 GPU。
2. 先用公开且许可清楚的中文音频；真实课堂需专门授权并控制保留。覆盖短／长段、停顿、语气词、回声与插话，不上传不必要的人脸视频。
3. 记录音频时长、总耗时、RTF=推理耗时/音频时长、冷启动、队列等待、峰值内存、CPU、失败率、重试与取消；保存硬件、版本和参数。
4. 有人工逐字标注后测 CER、语气词召回／误报、时间戳偏差；把转写错误与口头禅规则错误分开。CI 只保回归，不当效果测量。
5. 从单作业递增负载，观察吞吐、P95 等待、OOM 和现有站点健康；并发上限由预先约定预算／SLO 决定，无数据前不报价容量、不承诺服务日期。
6. 用户拍板允许上传、保留时限与成本上限后，才实施可选录后服务；失败仍可纯视觉或用户选择本机听写。实时服务与团队后台另开范围。

推荐组合为“本地视觉 + 可选自建服务器录后转写 + 可选离线”，**推荐不是已上线**。
