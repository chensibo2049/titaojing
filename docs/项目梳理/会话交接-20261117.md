## 发布流程（每次一样）

```bash
cd ~/AlmaProjects/体态镜
npm run build && npm test && npm run check-docs && npm run smoke
node scripts/检查双端布局.mjs
bash scripts/部署静态站.sh quan2        # 只认 quan2，只传 dist
curl -sS https://openpodium.chensibo.cn/version.json   # 核对 buildId
```

- 部署是 `releases/<UTC时间>-<buildId>` + `current` 原子软链，**不改 nginx、不 reload**。
- 回滚：把 `current` 链回上一个 release（见 `docs/OpenPodium部署记录-20261116.md`「回滚」）。
- 版本号改 `package.json` + `package-lock.json` + `scripts/check-v11.mjs` 里那条断言 + `src/changelog.js` + `CHANGELOG.md`，五处要一起改，否则 `npm test` 会失败。

## 踩过的坑

- **GitHub 网络会抖**：`git fetch/push` 偶尔 `Empty reply from server`，重试即可；GH CLI 操作通常不受影响。
- **CI 的 smoke 曾因首页 3D 超时**：`networkidle0` 等不到 → 改成 `domcontentloaded` + 等 `#cover-stage`。若恢复首页 3D，注意别再阻塞 load。
- **`赋能` 是禁用词**，但「AI 赋能教育计划」是专有名词，检查脚本已单独放行；其他场合仍禁止。
- 回放页在手机上是 `display: contents` 扁平化 + `order` 排序，加新块必须显式给 `order`，否则会跑到视频前面。
- 中文目录：脚本里一律 `fileURLToPath`，不要用 `URL.pathname`。
