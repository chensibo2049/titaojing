# 执行优先级与验收清单

> 内部工作文档｜2026-11-17 北京时间。无日期承诺；除本轮事实整理外全部待办。角色是后续责任交接建议，不代表已派发任务或已开工。返回[总览](项目总览.md)。

## 1. 范围控制

本轮只交付五份中文梳理文档，不改源码、不改旧文档、不提交推送、不部署、不启用 harness，不装模型、不改服务、不调用付费 API、不上传真人音视频、不写业务记忆。

后续遵循“小闭环先于大平台，真证据先于新皮肤”。Core 保持中立观测是产品原则；完整的架构解耦、服务端 ASR 与团队平台不能借本次整理被标为完成。

## 5. 四条就绪门槛与通过证据

| 门槛 | 必须看到什么 | 不接受的替代品 |
|---|---|---|
| 真实 | 真人来源、授权、原始依据；demo 明确预设 | 动画骨架冒充视觉识别、合成数据冒充真人 |
| 完整 | 开始—练习—结束—回看—选一处，失败也有解释 | 只有漂亮截图、只跑入口或播放按钮 |
| 可核验 | 提交、构建、设备、输入模式、时间戳、测试范围和原始证据可追溯 | main 已合并等同线上全功能通过、只看 version 元数据 |
| 用户价值 | 本人找到时刻、选出可复练动作，后续真实反馈 | CI 全绿、指标很多、开发者自评有用 |

## 6. 只保留两组需要用户拍板的问题

1. **首期人群与视觉方向**：是否先聚焦“师范生／教师两分钟试讲”，将路演／大会表达保留为次场景？UI 选“现有纸墨做减法”还是“暖白松绿练习室”？用户确认前不把暖白写成定稿，不大改主题。
2. **语音与数据边界**：是否接受“可选自建服务器录后转写”进入验证？若接受，需同时定上传授权、保留／删除策略、资源与成本预算；若暂不接受，继续本机视觉＋用户自选浏览器／本机听写，不承诺并发。

其他能据源码决定的事实不再反问。具体保留时限和 SLO 由验证方案提出后批准，不在本轮凭空指定。
