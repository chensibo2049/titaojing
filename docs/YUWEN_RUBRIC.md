# 语文试讲观察表

这份表给语文试讲、教资面试回看用。只摆事实，不做评分。

能从转写和时间戳里定位的，列出原话和时刻；镜头或录音看不出的，用自查清单，由试讲的人自己勾。每一条旁边有一句方法提示，来自师范生备考笔记。打印本页，或在软件回放里的「观察记录」中查看同一张表。

开讲前可在开讲页选填「题干要求」，把试讲题目或考题里的 2–3 条粘进去。回看时会对照转写，看这些词有没有讲到。不填也不影响其他栏目。

---

## 教资面试第一法则

先看教态与口头表达。回放里这一栏会把已有的姿态、视线、手势、语速、停顿和提问汇成一张总览，仍然不作好坏打分。

提示：学生读完、答完，要评在点上：读得好在哪、你抓住了……。教资面试第一法则，先看教态与口头表达。

## 二十三条备考笔记

下列文字尽量保留原来的说法，只做了轻分类。来自师范生备考笔记。

### 以生为本、师生对话、民主

1. 以生为本，课堂要民主。把对话还给学生，少唱独角戏，师生对话才显出民主。
2. 多用开放问题：「谁来说说」「你怎么看」「你觉得」，把思考权交给学生。
3. 要点名，照顾到不同的学生，不要只问全班齐答。
4. 有生无生结合：虚拟师生互动也要像真的对话，提问不少于 3 个，有问有候有评。

软件里会统计面向学生的用语比例、开放问题出现的时刻、点名用语，以及问句是否达到 3 次。

### 紧扣题干

5. 试讲要求里写了什么就落实什么，题干里的 2–3 条，课上要对得上。

若在开讲页粘贴了题干，会列出题干中的词在转写里覆盖到了哪些、哪些还没出现。

### 朗读

6. 朗读不少于三次，且要变换形式。齐读、点读、范读、分角色，目标至少三次，每次换一种办法。
7. 范读要注意语速和停顿。听老师读、我来读的那一段，语速要稳，停顿要留给诗句喘气。
8. 朗读要指导：要说出「读出」「重音」「停顿」「读慢一点」「入情」，不要读完就过。

软件按「齐读 / 全班一起读 / 请你来读 / 我来读 / 听老师读 / 分角色 / 男生读女生读」等用语切分朗读段，并统计形式是否有变化。打开模拟学生时，说「齐读」会看到全班齐读的动作，说「请你来读」会有一位同学站起来读。

### 板书

9. 板书要有过程：写板的时机要跟讲解中的关键词对上，让学生看见思考是怎么写上去的。
10. 主板书、副板书要分开。主板书承题干与结构，副板书随课堂生成，两块不要挤在一起。
11. 用彩色粉笔突出重点。重点字词、诗眼用彩色粉笔标出来，让学生一眼看见。
12. 板书布局要清楚。先想好位置再写，不要写完才发现挤成一团。

写板次数、时长和附近的原话，能从画面里的写板时段对上的，会列出来。主副板书、彩色粉笔和布局，需自己对照录像勾选。

### 炼字与过程

13. 炼字、换字比较：用「换成」「改成」「如果把 X 换成 Y」来比，让学生自己品出好在哪里。
14. 不要把换字的结论直接塞给学生。少说「为什么不用……用……」这种自问自答，把比较的过程留给学生。
15. 重过程，不直接给结论。别一上来就说「十分经典」「非常好」「表达了作者……的思想感情」，要先问再收。
16. 不要说「翻译」，改成「谁来说说这句话什么含义」。
17. 不要句句翻译。不要把诗一句句译成白话就完事，要留下品读的空间。

软件会标出换字比较、以及「为什么不用……用……」「翻译」「十分经典」一类说法出现的时刻；若这些结论出现在问句之前，会单独标出，便于回看。

### 教态、语文味与学法

18. 教态与肢体：手不要长时间不动，也不要一直比划；眼神、视线要照顾全场；姿态放松。
19. 节奏停顿。停顿是技术。问完、读完、写完，都要敢把时间留出来。
20. 语文味、情感：课里要有情感词，要能入情入境，让语文课像语文课。
21. 高中诗歌要抓住意象、意境、想象、情感；并留下批判性思维：你同意吗，有没有不同看法。
22. 学法五看：篇、段、句、词、意。还要言文结合，做减法，看共性也看个性，虚实、面点结合，抽象与具象互转。

学法五看与几对关系，用自查清单勾选。手是否长时间静止或一直在动、视线左右覆盖、停顿次数，能从姿态和转写里计算的会列出来。姿态是否放松，仍请自己对照录像。

### 评价

23. 教-学-评一致，做表现性评价：学生读完、答完，要评在点上，如「读得好在哪」「你抓住了……」。教资面试第一法则，先看教态与口头表达。

## 使用说明

- 这不是评分表，也不输出分数。
- 转写来自本机听写，目前只对普通话口说可靠；听写有误时，条目可能漏记或误记，以录像为准。
- 「练习用模拟」里的学生反应是本机规则演算，不是真实课堂。
