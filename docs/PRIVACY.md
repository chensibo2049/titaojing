# 隐私说明

体态镜把分析放在这台设备的浏览器里完成。下面按「会收集什么 / 到哪里去 / 你能怎样控制」写清楚。应用内「关于与隐私」和首次使用说明与本文一致。

## 默认（未参加体验计划）

| 数据 | 是否离开这台设备 | 说明 |
|---|---|---|
| 摄像头画面、录像 | 否 | 只在本机分析；录像默认不保存，勾选后写入本机 IndexedDB，可随时删除。 |
| 教态关键点、事件、历史记录 | 否 | 存在本机 IndexedDB。 |
| 转写文本、口头禅 | **视听写方式而定** | 本机识别（当前版本尚未接入，还不能用来转写）声音和文本都不出本机。**默认的浏览器听写**：Chrome / Edge 会把声音送到**浏览器厂商**的语音服务（不经过沉思波）。Safari 使用系统听写。体态镜只在本机留下转写结果。 |
| 反馈 | 否 | 「反馈问题」只生成文字或文件，由你自己决定是否发出，不含视频、声音或图片。 |
| 账号、统计脚本、广告、第三方 Cookie | 无 | 不使用。资源（含姿态模型）随程序提供或从你自己的 https 主机加载。 |

## 能录多长时间、分析多长时间

- 练习模式可选 1 / 2 / 3 / 5 分钟；课堂模式可选 10 / 15 / 20 分钟。到建议时长会提示，可以再讲一会儿，硬性上限是 22 分钟。
- 分析在这台设备的浏览器里、随录制进行，时长与这一次录音相同。结束后不会继续分析，除非你稍后回放已经保存在本机的记录。
- 删除记录和录像：打开「历史记录」，可删除单次、只删除录像，或全部删除。

沉思波**在默认情况下不接收你的任何数据**。没有配置上传地址时，即使参加了体验计划，也不会发到任何服务器。云端账号尚未开通；可选的本机练习档案也只存在这台设备上。

## 体验计划（默认关闭，需主动勾选）

首次使用时可勾选，也可随后在「关于与隐私」里打开或关闭。

若打开，每次试讲结束后，体态镜可能把下面这些内容排进**本机待发送队列**（可查看、单条删除、全部清空）：

- 口头禅词表及本次命中统计；
- 转写文本（不含音频）；
- 教态 / 视线 / 板书次数和回放里的两句说明；
- 最多三张回放截图（jpeg）。

**录像和麦克风音频默认不会进入队列，也不会上传。**

只有同时满足以下条件才会真正发出：① 你已勾选参加；② 管理员在 `config.js` 里填写了 `experienceEndpoint`；③ 你或程序触发「尝试发送队列」。当前发行版的端点为空，因此**不会发到任何地址**。若将来启用，接收方、保存期限和用途会写在本页和关于页，并另行告知。

关闭体验计划后，不会再入队；已在队列里的条目不会自动发送，你可以清空。

## 研究用轨迹

调试模式（`?debug=1`）可导出不含视频的关键点轨迹，用于排错或经同意的教学研究。研究采集必须另作知情同意，见 [`TRAINING.md`](TRAINING.md)。

## 未成年人

本工具面向成年师范生和教师。不要在有中小学生出镜的真实课堂里开启采集或体验计划。
