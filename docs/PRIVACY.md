# 隐私说明

> 2026-11-17 修订。OpenPodium · 开讲（原体态镜）当前以浏览器本机视觉与记录为主；不同听写方式的数据去向不同，不承诺所有情况下完全离线。

## 默认数据去向（未参加体验计划）

| 数据／请求 | 到哪里去 | 你能怎样控制 |
|---|---|---|
| 摄像头画面、录像 | 视觉推理在本机，不向本项目上传视频。录像默认不保存；勾选后写入当前浏览器 IndexedDB。 | 开讲前决定是否保存；历史中可删除单次、只删录像或全清。 |
| 关键点、事件、题干、本机档案、历史与报告 | 当前设备、当前站点的浏览器存储，无云同步。 | 可按记录删除或导出；导出文件需自行保管，浏览器删除不会撤回导出副本。 |
| 本机听写的声音与转写 | sherpa-onnx WASM + Paraformer int8 在本机识别，不经过沉思波或浏览器厂商 ASR 服务。 | 约 90 MiB 引擎与模型需先就绪；新用户默认不自动下载，可主动下载或开启自动下载，旧显式开启设置保留。 |
| 浏览器听写的声音 | Web Speech 可能发送给浏览器／系统厂商；具体由其实现和隐私政策决定。本项目在本机保存返回的转写。 | 可不启用听写，或选择仅本机；自动模式本机未就绪时可能使用浏览器服务，不能套用本机“不上传声音”的保证。 |
| 网站、视觉和听写资源下载 | 访问本站及所选模型镜像，托管方可获得 IP、请求时间等常规访问日志；模型请求不包含练习音频。 | 首次使用与缓存失效后可能联网；本机模型缓存齐全且浏览器兼容时可离线识别，不能承诺首次零联网。 |
| 反馈与调试导出 | 先生成本机文本／文件，是否发送由用户决定；不默认自动上报练习数据。 | 发出前检查题干、转写、关键点、设备信息等敏感内容。 |

当前没有已开通的云账号、团队后台、安全收费授权、广告或应用内统计脚本。前端 trial/pro 与本机档案不是云账号。不要把“本项目不上传录像”扩大为“资源托管方没有日志”或“浏览器听写绝不传音”。

### 服务器 ASR：未上线

服务器 provider 正在实施，公网接通与上线未确认，暂不作为可用服务。**模型文件托管不等于服务器识别**；若未来启用服务器 ASR，音频将需要上传，必须在使用前明确接收方、用途、传输方式、访问控制、限额、保留期限和删除方式，并由用户主动同意。当前不能凭实施中的代码承诺数据不离开设备或服务已经可用。

## 本机存储、时长与来源

- 练习可选 1 / 2 / 3 / 5 分钟；课堂可选 10 / 15 / 20 分钟，到建议时长提示，硬上限 22 分钟。具体设备的长时稳定性需单独验证。
- 分析随本次练习进行，结束后生成回放／报告；本机历史不是持续后台采集或云备份。
- 本地视频导入只做视觉分析和当前回放，不处理音轨、不转写、不统计口头禅、不存入历史。
- demo 是动画 rig 与预设字幕／结果，不采真人识别数据，不是实际用户案例。
- 旧技术存储 ID（如 `titaojing-*`）保留，避免更名破坏历史。主力站与 Pages 是不同域的独立存储，换域名、设备或浏览器不会自动迁移。
- 浏览器配额、隐私模式或清站点数据可能导致历史和模型丢失。设置可删除听写模型，但不承诺同时清除所有引擎缓存和残余下载分段；需清除该域全部数据时使用浏览器站点数据管理，并先自行保管需要的导出物。

## 体验计划（默认关闭，需主动勾选）

可在首次使用或“关于与隐私”中选择。开启后，每次练习可能将以下内容排入**本机待发送队列**，可查看、单条删除或清空：

- 口头禅词表与本次命中统计；
- 转写文本（不含音频）；
- 教态／面向／板书次数与回放说明；
- 最多三张回放截图（jpeg）。

录像和麦克风音频默认不入队、不上传；但**截图与转写仍可能识别个人，不等于匿名数据**。

真正发送必须同时满足：① 用户已同意参加；② `config.js` 配置了 `experienceEndpoint`；③ 用户或程序触发发送。当前发行基线端点为空，因此不向体验计划后台发送。关闭后不再入队，也不自动发送旧队列，可手动清空。未来启用前需另外明确接收方、用途、保留期限和删除办法，并同步界面告知；不能把预留发送函数称为已部署的业务后台。

## 研究、展示与未成年人

调试模式（`?debug=1`）可导出不含视频的关键点轨迹；轨迹和文本仍可能敏感。研究需独立知情同意，见 [研究说明](TRAINING.md)。公开展示真人片段、转写或前后对比，需获得具体展示范围与保存期限的授权；没有案例时只能标为预设演示，不生成用户证言。

本工具面向成年师范生、教师与表达练习者。不要在有未授权中小学生或其他同伴出镜／出声的真实课堂开启采集、体验计划或第三方听写。

听写细节见 [ASR](ASR.md)。本文描述当前实现边界，不表示应用内各渠道已在本轮逐项复测；未来启用上传服务时应一并更新告知和验收。
