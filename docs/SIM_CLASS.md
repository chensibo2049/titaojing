# 模拟课堂（练习用）

这是给试讲练习用的模拟听众，**默认关闭**。打开后，画面旁边会出现几位虚拟同学，或三位路演嘉宾／评委。全部在本机按规则演算，不调用任何在线服务，也不是真实课堂。页面上会标明「练习用模拟」。

WebGL 可用时，模拟同学和嘉宾默认使用 Microsoft Rocketbox（MIT）里更写实的绑定人物。显卡弱、软件渲染，或在设置里选择「只用插画」「流畅优先」时，退回原来的插画。人物来源与限制见 [CHARACTERS.md](CHARACTERS.md)。

## 怎么打开

在开讲页（允许镜头之前）选择「模拟学生」或「模拟路演」。设置页里也可以改，下一次试讲生效。

## 模拟学生会做什么

- 您说「谁来回答」「请这位同学」「有没有同学」「大家说说」时，多数同学举手。
- 点其中一位，或者说「请你」「请这位」，也可以在举手时向左或右侧伸手，即点名。
- 被点到的同学从题库里给出一句回答，显示在对话框里。回答有正确、不完整、有误三种，方便练习追问。
- 若这台电脑的浏览器里有中文语音，回答会读出来；没有则只显示文字。
- 超过约 8 秒没有说话，或一段里语速很快，会有同学露出困惑或走神。

## 模拟路演会做什么

讲完一段，或说「大家有什么问题」，一位嘉宾会提出常见问题，例如：差异化、收费、用户是谁、下一步计划、团队分工。同时开始倒计时。您开口后，会记下这次回应用了多久。

## 回放里能看到什么

观察记录里有「模拟互动」：互动次数、点名分布、回应时长。若这次没有打开模拟，该栏会写明原因。

## 怎么改题库

题库是一份普通的 JSON 文件：[`assets/classroom/banks.json`](../assets/classroom/banks.json)。老师可以直接改学生姓名、提问用语和回答，保存后重新打开体态镜即可。不必联网，也不必重新编译。请保持 JSON 格式正确；学生建议 4 到 6 位，路演嘉宾 3 位。

回答请同时准备一些正确的、一些不完整的、一些有误的，这样更适于练习追问。

## 朗读口令

在模拟学生模式下，除了点名和回答，还可以练朗读组织：

- 「齐读」「全班一起读」「我们一起读」「分角色」「男生读」「女生读」：全班进入齐读。
- 「请你来读」「请这位同学读」，或「请林秋来读」：一位同学站起来读。
- 「我来读」「听老师读」「跟着老师读」：同学进入听读。

这些口令写在题库的 `readChorusCues`、`readPointCues`、`readModelCues`、`readRoleCues` 里，可直接改。口令优先于普通的「请你」点名，避免「请你来读」被当成普通回答。
