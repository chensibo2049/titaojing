# 语文试讲观察表：依据与延伸阅读

本页配合 `docs/YUWEN_RUBRIC.md` 使用，回答的是「为什么观察这一项」。它**不是评分标准，也不产生分数**。观察表里「能从转写、画面里定位的摆事实，看不出的由本人自查」这条原则不变。

这是一份讨论稿：下面的对应关系请核对原书、原刊后再引用。

## 二、二十三条笔记对应的依据

### 以生为本、师生对话、民主（1–4）

- 义务教育课标明确学生是学习的主体，教师是组织者、引导者与合作者；高中课标把「语言运用」放在四项核心素养的基础位置。
- 王宁谈课标时说，素养是面对学生的，教学设计就必须以学生为主体。
- 叶澜「五实」里的「扎实」「充实」，看的是学生有没有真的学到，而不是教师有没有讲完。
- 提醒：开放问题不等于随便发散。王荣生强调「凡是有说服力的解读，一定是有文本证据的」，追问要能回到「你从课文哪个词、哪句话读出来的」。

### 紧扣题干（5）

- 王荣生《阅读教学设计要诀》的三句话：依体式定终点、研学情明起点、中间搭两三个台阶。题干要求是「终点」的一部分，不是另加的表演任务。
- 提醒：十分钟试讲最常见的失误，是把四十五分钟压缩着讲完；宁可只走完两三个台阶。

### 朗读（6–8）

- 两个学段的课标都把诵读作为阅读教学的重要方式，要求在读中感受语言节奏、体会情感；古诗文尤其强调诵读积累，而不是逐句译成白话。
- 提醒：变换朗读形式是为了留出品读空间，不是为了凑次数。「不要句句翻译」和「重视诵读」是同一件事的两面。

### 板书（9–12）

- 余映潮「板块式教学」「主问题」：板书要能看出课堂的板块与思路，随讲随写，而不是先写满一黑板。
- 提醒：写板时背对学生、写完不回视，正是观察表要留板书区静帧的原因。这一项是体态观察，不是板书美观评分。

### 炼字与过程（13–17）

- 孙绍振文本解读的还原法、比较法：把字换一换，把矛盾处摆出来，让学生自己品出好在哪里。
- 黄伟「三层级阅读教学」：释义层（写了什么）→ 解码层（怎么写的）→ 评鉴层（写得如何、于我何用）。把「抒发了什么情感」改成「作者如何抒发情感」，课堂就从浅层进到解码层。
- 王荣生「变『讲课文』为『教读法』」：要教的是「这一类怎么读」，不是「这一篇写了什么」。
- 肖培东评「一字立骨」时的提醒：「你是基于教的教学，还是基于学的教学，这极为关键」——别把自己的解读结论直接告知学生。
- 提醒：观察表标出「为什么不用……用……」「十分经典」「翻译」一类说法，理由就在这里；这些结论出现在问句之前，说明给早了。

### 教态、语文味与学法（18–22）

- 课标把思维能力、审美创造列入核心素养；高中课标设「思辨性阅读与表达」学习任务群，对应「你同意吗，有没有不同看法」。
- 朱永新「理想课堂六度」中的参与度、亲和度、自由度、练习度、延展度，可作课后自查的五个角度，同样不打分。
- 支玉恒谈教态时说，与学生是心与心的交流，而不仅仅是「教态」如何；手势、站位要有实际指向（指板书、请人回答），不要变成表演。
- 提醒：观察表能算的是手是否长时间静止、视线左右覆盖、停顿次数；「姿态是否放松」仍由本人对照录像勾选，不要把镜头估计当成结论。

### 评价（23）

- 义务教育课标（2022 年版）强调教、学、评的一致，倡导表现性评价：评价要落在学生具体的读与答上，而不是笼统地说「很好」。
- 提醒：「读得好在哪」「你抓住了……」是给证据的评价；「不错」「非常好」不是。

## 三、难度与学段：两条自查线

- **起点**：先研学情，再定终点。难度不按教师讲得深不深算，按学生够不够得着算。
- **台阶**：一节课只搭两三个台阶。布鲁姆的认知层级用来排活动顺序，SOLO 分类用来定追问方向，课标的学业质量水平用来定学段深浅。
- **发散有边界**：允许不同解读，但要求回到文本证据。这既不压学生，也不放任。
- **学段别混**：小学、初中看 2022 年版义教课标，高中看 2017 年版 2020 年修订版。两套课标的核心素养表述与任务群不同。

## 四、延伸阅读从哪里找

1. **课标原文与官方解读**：教育部发布的两本课标，以及对应的《义务教育语文课程标准（2022 年版）解读》《普通高中语文课程标准（2017 年版 2020 年修订）解读》。
2. **语文教育期刊**：《课程·教材·教法》《语文建设》《中学语文教学》《语文教学通讯》《中学语文教学参考》《语文学习》《小学语文》。查目录用知网、万方的期刊导航，别用第三方代发站。
3. **教研著作**：王荣生《阅读教学设计要诀》、叶澜关于「五实」的论述、孙绍振文本解读系列、余映潮板块式教学相关著述、黄伟三层级阅读教学相关论文。书名与篇名请按图书馆或知网条目核对后再引用。
4. **公众号只作入口**：语文旅思（黄伟三层级）、语文湿地、正道语文、语文深深浅浅之间（肖培东）、杰哥的精致语文（徐杰）、祖庆说、王崧舟、语文潮（余映潮）、西湖语文等。推文常在文末注明原刊，写参考文献请引那一处。
