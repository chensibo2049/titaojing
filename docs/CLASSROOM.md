# 课堂摆放指南

把一台笔记本放在讲台或课桌上，用自带的摄像头讲 10 到 20 分钟，再回看。不必另买设备。练习模式仍然保留（默认 2 分钟），适合日常对着镜头反复练同一处。

## 1. 电脑放在哪里

- **讲台上**（最常见）：合上一些屏幕倾角，让镜头大致与胸部齐平或略低。俯拍会让「视线」看起来总在低头。
- **第一排课桌**：适合讲台太高、或你需要全身入画的时候。镜头对着讲台，稍偏侧前方，不要正对黑板反光。
- **教室侧前方**（全身）：把电脑或手机架在靠窗一侧、大约第二排的位置，能拍到人的头和脚，以及黑板的一侧。请同伴帮忙看一下构图。

用支架或书本把镜头垫稳，避免学生经过时碰到。插上电源。讲课前先开一次「对着镜头试讲」，看自己是否在框里，再结束、正式开始。

## 2. 光线

- 光线从**正面或侧前方**来。窗在身后会变成逆光，面部和肩线都不稳。
- 关掉正对镜头的强射灯；黑板如果反光，稍微偏一点角度。
- 教室太暗时，打开讲台附近的灯即可，不必把所有灯都开到最亮。

## 3. 两种构图

| | 半身 | 全身 |
|---|---|---|
| 画面里应看到 | 头、肩、手、腰部以上 | 从头到脚，黑板一侧也可见 |
| 距离（大约） | 1–2 米 | 3–5 米，或教室侧前方 |
| 更能看见 | 视线是否落在讲稿上、肩是否晃、写板后回不回看 | 站位、步伐、写板时会不会整个人背对学生 |
| 怎么选 | 设置或开讲页选「半身」；也可「自动判断」 | 选「全身」，或自动判断（能看见膝盖、脚踝则为全身） |

封面的示范画面会在半身和全身之间切换，便于向同事或学生说明这两种摆法。

## 4. 建议流程（课堂模式）

1. 在设置里选「课堂」，建议时长 10、15 或 20 分钟（最长再加 2 分钟，不超过 22 分钟）。
2. 打开麦克风。转写需要它：回放里会留下文本，并标出水词。
3. 按平常的样子讲，不必盯着屏幕。切到其他窗口或锁屏会自动暂停。
4. 结束后先看回放和时间线，再看转写。可以打印一页小结，或把这一次留在本机历史里和上一次比。
5. 录像默认不保存。若要留给教研组一起看，在开讲前勾选「把录像存进本机历史」，并注意磁盘空间（20 分钟可能有几十到一百多 MB）。

电脑放在讲台上时，不必走回去点按钮：站好构图后按 **空格**（或回车）开始倒计时（课堂模式 5 秒、练习模式 3 秒，按真实秒数倒数），走到位置即可开讲；到最短时长后再按空格结束。练习模式最短约 15 秒即可结束；课堂模式至少讲 1 分钟后才能结束，以免误触。正在输入文字、观看演示、或弹出层打开时，空格不会误触。

回看时也不必去点进度条：按 **空格** 播放 / 暂停，**← / →** 前后跳 1 秒，按住 **Shift** 一次跳 5 秒；**PgUp / PgDn**（或 **[ / ]**）跳到上一处 / 下一处时间线提示（提前 1 秒，便于看清前因），**Home / End** 回到开头或结尾。焦点在按钮上时，空格仍只按那个按钮。

想要一份按时间分好的流程，见 [试讲练习单](PRACTICE.md)。

## 5. 常见问题

- **骨骼线对不上 / 经常提示看不到人**：镜头太近、只拍到头肩，或逆光。退后，让腰（半身）或脚（全身）进入画面。
- **一直显示在看讲稿**：镜头太高，变成俯拍。把电脑垫低。
- **转写是空的**：未允许麦克风，或用了不支持听写的浏览器（Firefox、部分国产浏览器、微信内置浏览器）。也可以是 Chrome 的听写连不上厂商服务：在中国大陆即使网页能打开、电脑有网，听写仍经常失败。可先点「试一下听写」，或改用 Microsoft Edge。更稳的办法是在「设置」里下载本机听写（约 90 MB，一次即可），之后不用联网，声音也不出这台设备，见 [`ASR.md`](ASR.md)。
- **认不出黑板上的字**：目前不能做板书文字识别。能看到手是否伸向板书区、是否在写、写完是否回视学生；写板时会留下板书区静帧，供你自己看字迹。
- **手机也能用吗**：能。课堂里更推荐电脑：屏幕大、回放好看，也省得一直举着手机。手机测试必须是 https 地址，见 [`CAMERA_DEBUG.md`](CAMERA_DEBUG.md)。

## 6. 模拟课堂（练习用）

开讲前可以打开「模拟学生」或「模拟路演」，用来练点名、追问和应对提问。这是本机规则演算的练习工具，**不是真实课堂**，默认关闭。详细说明和题库改法见 [模拟课堂](SIM_CLASS.md)。
